# Changelog

## 0.1.0 — Telegram Mini App MVP

- Мобильный интерфейс Home / Hot / Playlists / Profile / Upload / Login.
- Поиск до 5 тегов, обязательные теги для загрузок.
- Вложения изображений/видео, фильтры, сортировка, Masonry/Grid.
- Telegram WebApp initData (HMAC), бот с кнопкой запуска.
- Лайки, закладки, плейлисты, просмотры, жалобы.
- Очередь модерации, admin API/экран.
- Smoke-тесты всех основных серверных сценариев.
